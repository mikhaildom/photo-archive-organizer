# photo-archive-organizer — порядок в семейном фотоархиве

Скилл для Claude (Claude Code, Claude.ai, Cowork), который помогает разобрать семейный архив фото и видео на компьютере:

- разложить свалку снимков со старых телефонов и фотоаппаратов по папкам-событиям `ГГГГ-ММ-ДД Описание`;
- восстановить даты съёмки, в том числе когда часы камеры не были выставлены;
- найти дубли, включая повёрнутые и уменьшенные копии;
- опознать места и отели по вывескам, логотипам и GPS;
- и при этом **ничего не потерять**: только перенос по согласованному плану, журнал всех действий, откат одной командой, удаление — только в Корзину и только после вашего «да».

Скилл вырос из настоящего разбора семейного архива на десятки тысяч снимков: правила в нём — это выводы из реальных ошибок и просьб.

## Установка

**Claude Code:** скопируйте папку `photo-archive-organizer` в `~/.claude/skills/` (Windows: `C:\Users\<вы>\.claude\skills\`).

**Claude.ai / Cowork:** упакуйте папку в zip и загрузите её в Настройки → Возможности → Скиллы (Settings → Capabilities → Skills).

Для скриптов нужен Python 3.9+:
```
pip install Pillow numpy
pip install pillow-heif send2trash   # по желанию: фото iPhone (.heic) и Корзина на macOS/Linux
```

## Как пользоваться

Просто попросите Claude, например:

> Разбери папку D:\Фото\Мамин телефон — разложи по событиям, найди дубли, ничего не удаляй без меня.

> У меня 5000 фото со старых телефонов вперемешку, помоги навести порядок.

> Где и когда это снято? Папка «2009 Турция».

Claude сначала посмотрит снимки (листы миниатюр), предложит план с именами папок, дождётся вашего согласия, выполнит его с журналом и расскажет, что сделано.

## Что внутри

```
photo-archive-organizer/
├── SKILL.md                 — правила и порядок работы
├── references/
│   ├── lessons.md           — уроки из реальных разборов
│   ├── dates.md             — откуда брать даты и где они врут
│   └── plan-format.md       — формат плана переносов
└── scripts/
    ├── inventory.py         — опись: даты, камеры, подозрительные даты (только чтение)
    ├── contact_sheet.py     — листы миниатюр (только чтение)
    ├── find_duplicates.py   — точные и визуальные дубли (только чтение)
    ├── apply_plan.py        — переносы по плану, журнал, откат (--go)
    └── to_trash.py          — в Корзину по списку (--go)
```

Скрипты, которые что-то меняют, без флага `--go` только проверяют и показывают, что будет сделано.

## Совет

Перед началом сделайте копию архива на внешний диск. Скилл осторожен, но копия — единственное, что спасает от отказа диска.
