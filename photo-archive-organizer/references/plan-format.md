# Формат плана для `apply_plan.py`

План — JSON-файл со списком операций. Пути — относительно `--root` (папки архива) или абсолютные.

```json
{
  "title": "Разбор папки «Мамин телефон», шаг 1",
  "ops": [
    {"op": "mkdir",  "path": "Мамин телефон/2010-12 Ёлка в школе"},
    {"op": "move",   "src": "Мамин телефон/Photo-0216.jpg", "dst": "Мамин телефон/2010-12 Ёлка в школе/Photo-0216.jpg"},
    {"op": "rename", "src": "2011-10-21 Лес", "dst": "2011-10-21 Пикник у бабушки на даче"},
    {"op": "note",   "path": "2019-09-09 Турция, Сиде/Отель.txt", "text": "Отель: …\nУверенность: …\n"}
  ]
}
```

| op | что делает | обязательные поля |
|---|---|---|
| `mkdir` | создаёт папку | `path` |
| `move` | переносит файл или папку; папка назначения должна существовать или создаваться раньше в плане | `src`, `dst` |
| `rename` | то же, что `move`, для читаемости плана | `src`, `dst` |
| `note` | создаёт **новый** текстовый файл (UTF-8 с BOM, чтобы Блокнот Windows открыл без кракозябр) | `path`, `text` |

Проверки до начала (ничего не выполняется, если хоть одна не прошла):
- источник `src` существует;
- цель `dst`/`path` ещё не существует (с учётом того, что раньше в плане она может быть создана или освобождена);
- одна цель не встречается в плане дважды.

Журнал: одна строка на операцию, табуляция между полями: `время  op  src  dst`. По нему `--undo` выполняет операции в обратном порядке (`move` назад, `mkdir` — удалить папку, только если пуста, `note` — в Корзину не отправляется, а переименовывается в `*.undone`, чтобы ничего не терять).
